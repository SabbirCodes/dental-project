# BrightSmile — Dental Booking Platform

## About BrightSmile

**BrightSmile** is a full-stack dental booking platform designed to connect patients with dental clinics. It provides specialized tools and dashboards tailored across four distinct user roles:

- **Patients (`user`):** Discover clinics and dentists, manage bookings, and leave ratings or reviews following completed visits.
- **Clinics (`org`):** Manage clinic profiles, dentist rosters, working hours, and incoming patient appointments.
- **Admins (`admin`):** Oversee platform operations and moderate clinic registration requests.
- **Superadmins (`superadmin`):** Access total platform control, configure system settings, and manage user/clinic data with cascading operations.

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Database:** MongoDB
- **ODM:** Mongoose
- **Authentication:** NextAuth.js (Credentials provider, JWT sessions)
- **Security:** bcryptjs
- **Data Fetching:** Axios
- **Validation:** Zod
- **Styling:** Tailwind CSS 
- **Animation:** Motion
